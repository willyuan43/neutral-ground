How we built it

A static web page that runs on any phone, even offline

Game

Vite, React 18 and TypeScript; three.js with React Three Fiber. One-file build of 13.5 MB that also plays offline.

Data and model

Public datasets on one 5 m grid of 211 × 280 cells. The model is plain TypeScript, with tests that reach every ending.

Art

Higgsfield: GPT Image 2.5 character art, Meshy 7 image-to-3D with auto-rigging, six shared moves. Slimmed with gltf-transform to about 2.8 MB.

Testing and AI help

Playwright playtests at laptop and phone sizes; independent review rounds; Claude for research, code, copy and bug audits.

The whole game is a static page: no server, no accounts, no data collected. It loads public data once and runs the model in the browser, so it also works as one offline file. Characters were generated with Higgsfield, turned into rigged 3D models with Meshy, and share one set of animations. We tested with automated playthroughs on desktop and phone screens.
