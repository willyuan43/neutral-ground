# Presentation（15 页）

- `Neutral-Ground-Presentation.pdf`：离线 PDF。本地渲染的，正文字体用 Inter 代替 Nunito Sans，排版和网页版几乎一样。
- 原账号的在线版：https://claude.ai/artifact/R1ZppPoApW5f64iYmniE7G。可以在线演示，也能下载 PowerPoint 或 PDF；演讲备注在每页里。
- `source/`：幻灯片源文件，用 Claude 的 Slides 格式写成。
  - `project/deck.json`：页序和字体。
  - `project/slides/*.html`：每页一个文件，最后的 `<aside>` 是演讲备注。
  - `img/`：游戏截图。
  - 在线版里图片的地址是 `/_blob/<id>`。
